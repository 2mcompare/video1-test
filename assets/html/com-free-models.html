04 — Key Takeaways
WHAT THIS TEST REVEALS
The patterns that emerged across 5 models tell us something real about how frontier AI systems handle complex, multi-constraint coding.
01
🪄
THE UNIVERSAL FAILURE
All 5 models produced invisible feature cards. Every single one. This is the hardest part of the prompt — glassmorphism + staggered IntersectionObserver + unique hover glows all layered together. It's the one thing that would separate a 9/10 output from a 7/10, and nobody cracked it in a single shot.
02
🧮
SVG MATH IS THE REAL TEST
The radar chart requires writing trigonometry from scratch. DeepSeek and Big Pickle got it right. Gemma drew a filled hexagon. Nemotron drew a random shape. Correct SVG coordinate math is a genuine frontier differentiator.
03
📏
SIZE ≠ QUALITY
Gemma 4 has 31B parameters and scored 4/10. MiMo v2.5 has 7B parameters and scored 7.5/10. Parameter count is not a reliable predictor of frontend coding performance.
04
💥
ONE BUG = EVERYTHING BREAKS
Nemotron's entire submission collapsed because of one syntax error on line 3 — CSS custom properties written as quoted strings. That single mistake killed 100% of the visual design.
05
🎨
PERSONALITY IS HARD
Big Pickle required being funny AND technically correct simultaneously. It scored highest on creativity because the model genuinely understood the joke. Most models would have played it completely safe.
06
🧠
THINK BEFORE YOU CODE
The "think step by step" instruction forces reasoning mode. MiMo's terminal and quiz — its strongest sections — show deep contextual understanding that only emerges when a model plans before executing.

06 — Final Verdict
SO WHICH ONE SHOULD YOU USE?
Based on what we saw — here's the honest recommendation for each use case.
🥇 Best for Frontend
DEEPSEEK V4 FLASH
If you need reliable, clean, multi-constraint frontend code — DeepSeek Flash is the clear winner. It follows complex specifications, uses modern JS patterns, and produces readable, maintainable output. Use it when you need something done right the first time.
🥒 Best for Creative Briefs
BIG PICKLE
When your prompt has personality, tone, and humor requirements alongside technical ones, Big Pickle handles the combination better than anything else tested. It understood the joke and executed it — and the code quality underneath is genuinely excellent.
🔶 Best Compact Model
MIMO V2.5
At 7B parameters, MiMo punches significantly above its weight class. For math, logic, and chain-of-thought tasks embedded in code, it's surprisingly capable. Don't sleep on small reasoning models for structured coding tasks.

NVIDIA's model failed at basic CSS syntax. For complex single-file frontend work it is not ready. Gemma 4 31B also disappointed given its parameter count — it handled structure but failed completely at implementing the hard parts. Surprising and disappointing.
