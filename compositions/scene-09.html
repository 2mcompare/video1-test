Key Takeaways

What this test really revealed about AI coding
01
🪄

The Universal Failure

All 5 models produced invisible feature cards. Glassmorphism + IntersectionObserver is the hardest part of the prompt.

02
🧮

SVG Math is the Real Test

Radar chart = trigonometry from scratch. DeepSeek & Big Pickle got it right. Gemma drew a hexagon.

03
📏

Size ≠ Quality

Gemma 31B = 4/10. MiMo 7B = 7.5/10. Parameter count is not a predictor of frontend performance.

04
💥

One Bug Kills Everything

Nemotron's quoted CSS variable on line 3 destroyed 100% of the visual design. Self-review is critical.

05
🎨

Personality is Hard

Being funny AND correct is rare. Big Pickle understood the joke — most models play it safe.

06
🧠

Think Before You Code

"Think step by step" forces reasoning. MiMo's strongest sections show deep contextual understanding.
