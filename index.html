Key Takeaways

What this test really revealed about AI coding
01
🪄

The Universal Failure

All 5 models produced invisible feature cards. Glassmorphism + IntersectionObserver is the hardest part of the prompt — nobody cracked it.

02
🧮

SVG Math is the Real Test

Radar chart = trigonometry from scratch. DeepSeek & Big Pickle got it right. Gemma drew a hexagon. Nemotron drew a random shape.

03
📏

Size ≠ Quality

Gemma 31B = 4/10. MiMo 7B = 7.5/10. Parameter count is not a reliable predictor of frontend coding performance.

04
💥

One Bug Kills Everything

Nemotron's quoted CSS variable on line 3 destroyed 100% of the visual design. Self-review is not optional.

05
🎨

Personality is Hard

Being funny AND correct simultaneously is rare. Big Pickle understood the joke — most models play it safe.

06
🧠

Think Before You Code

"Think step by step" forces reasoning mode. MiMo's strongest sections show deep contextual understanding from planning first.

Final Verdict

For Frontend

DeepSeek V4 Flash

Reliable, multi-constraint code that follows complex briefs without going off the rails. Use it.

For Creative

Big Pickle

Personality + technical requirements — holds both registers simultaneously. Exceptional.

For Small Models

MiMo v2.5

7B parameters, 7.5/10. Remarkable. Punching way above its weight class.

Avoid for Frontend

Nemotron & Gemma 4

Neither is ready for complex single-file frontend work. Gemma may surprise on other tasks — but not frontend.
